The seagull is a MODIFIED pigeon. The pack ships it as Pigeon.gltf with its
buffer base64-embedded; it was repacked as a .glb (the build hook imports
.glb) and its 32 x 32 palette atlas was repainted as a herring gull: the
grey wings -> gull grey, the purple body and head -> white, the orange
beak and feet -> yellow; the eyes are unchanged. Geometry, rig and animations are byte-identical to the
original. (Poly Pizza's CDN served empty bodies to this network, so the
source file came from a GitHub mirror of the pack; two independent
mirrors are byte-identical, md5 3a12019cdd0c3edae9b04a6fbdded0ca.)

The Nature Kit .glb files here have been PREPROCESSED. Kenney's exports
carry an orphan node named "tmpParent" that is not in any glTF scene but
lists the scene's root node as its child. flutter_scene 0.23.0 realizes
every node in the document, so that node claims the root first and the
loader then throws "Child already has a parent" -- loadScene fails outright
on the stock file. The orphan node was pruned (and node indices remapped)
before committing; the pruning script and the full diagnosis are in
docs/hybrid-demo/06-island-scene.md.

A second, separate trap in the same kit: tree_palmDetailedTall.glb and
tree_palmDetailedShort.glb carry two sibling nodes both named "leafs",
which fails the same way and cannot be fixed by pruning. Those two models
are avoided; tree_palmTall.glb is used instead.

The island landmass itself is not an asset -- it is generated from
flutter_scene primitives in lib/tabs/scene/island_scene.dart, so the
tap-to-move ground plane and the visible terrain are the same geometry by
construction.

Note: these .glb files are the SOURCES. The flutter_scene build hook
(hook/build.dart) converts them to .fsceneb under flutter_scene_generated/
at build time; that directory is generated and gitignored. Load them by
their source path -- loadScene('assets/models/tree_palm.glb').
